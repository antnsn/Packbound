# Commands

Everything in Packbound can be set in the options window (`/pack`). These chat commands are shortcuts.

`/packbound` works everywhere `/pack` does. Commands only do something on a hunter.

## Windows

| Command | What it does |
| --- | --- |
| `/pack` | Opens or closes the options window. `/pack options` and `/pack config` do the same. |
| `/pack help` | Lists every command in chat. |

## Ammo

| Command | What it does |
| --- | --- |
| `/pack pet` | Says in chat what Packbound sees about your pet: out or not, happiness, Feed Pet, the food it would use. |
| `/pack ammo` | Sets a waypoint to the nearest vendor who sells your kind of ammo, and says in chat who and where it is. See [Ammo](features/ammo.html). |

## Frames

| Command | What it does |
| --- | --- |
| `/pack unlock` | Shows every frame so you can drag and resize it. See [Frames](features/frames.html). |
| `/pack lock` | Locks the frames again. |
| `/pack move` | Unlocks the frames, or locks them if they are unlocked. |
| `/pack reset` | Puts every frame back in its default place and size. |
| `/pack grid` | Turns snapping to the grid on or off. |
| `/pack grid 30` | Sets the grid size (4 to 100) and turns snapping on. |
| `/pack minimap` | Shows or hides the minimap button. |

## Tooltips

| Command | What it does |
| --- | --- |
| `/pack explain` | Turns the plain-word [explanations in tooltips](features/explanations.html) on or off. |

Each command also works without the space, for example `/packunlock` or `/packammo`, for chat setups that swallow Enter after a space.

Type anything else after `/pack` to get the list of commands in chat.

The [buff key](features/buff-key.html) is not a command: set it on the **Extras** page of `/pack`.
